## 🚀 КАРТОЧКИ УЛУЧШЕНИЙ (№ 149 - 156)

### 🔴 149. Внедрить обязательные Skeleton Screens во фронтенд-шаблоны (L4)
*   **Тип**: Новое правило / Дополнение L4
*   **Приоритет**: КРИТИЧЕСКИЙ
*   **Суть**:
    *   Запретить ИИ использовать spinners или простые текстовые загрузки типа "Загрузка...".
    *   Обязать модель генерировать семантические скелетоны карточек, списков и таблиц с анимацией пульсации `animate-pulse` для сглаживания субъективного ожидания.
    *   *AI DX Эффект*: Скелетоны легко генерируются ИИ, если предоставить четкую структуру разметки, и они значительно улучшают восприятие скорости работы приложения.

### 🟡 150. Стандартизация хука useOptimistic для быстрых транзакций данных (L4)
*   **Тип**: Дополнение L4
*   **Приоритет**: ВЫСОКИЙ
*   **Суть**:
    *   Обязать ИИ применять паттерн Optimistic UI (через `useOptimistic` в React 19) для действий, требующих немедленного отклика (лайки, чекбоксы, удаление строк, добавление в корзину).
    *   Прописать паттерн автоматического отката состояния (rollback) при сбое сети.
    *   *AI DX Эффект*: Избавляет ИИ от написания сложных кастомных стейт-машин для обработки ожидания ответа сервера.

### 🔴 151. Внедрить обязательный аудит доступности (a11y) на этапе генерации UI (L0)
*   **Тип**: Новое правило / Дополнение L0
*   **Приоритет**: КРИТИЧЕСКИЙ
*   **Суть**:
    *   Добавить в фундаментальные правила жесткий чек-лист доступности для ИИ: все изображения должны иметь содержательный `alt`, интерактивные кнопки — семантический тег `<button>` или `<a href>`, а иконки без текста — `aria-label`.
    *   *AI DX Эффект*: Предотвращает генерацию несемантического кода (бесконечных кликабельных `<div>`), который ломает навигацию с клавиатуры и делает продукт недоступным для скринридеров.

### 🟡 152. Зацикливание фокуса (Focus Traps) в правилах модальных окон ИИ (L4)
*   **Тип**: Дополнение L4
*   **Приоритет**: ВЫСОКИЙ
*   **Суть**:
    *   Запретить ИИ генерировать самописные модальные окна без удержания фокуса. 
    *   ИИ должен использовать примитивы Radix UI, `@radix-ui/react-dialog` или готовый `<Dialog>` от Shadcn/ui, которые предотвращают уход фокуса на фоновые элементы при нажатии `Tab`.
    *   *AI DX Эффект*: Исключает баги с клавиатурной доступностью, которые часто возникают при генерации модалок ИИ с нуля.

### 🟡 153. Стандартизация декларативной анимации Framer Motion во фронтенде (L4)
*   **Тип**: Дополнение L4
*   **Приоритет**: ВЫСОКИЙ
*   **Суть**:
    *   Запретить ИИ писать сложные императивные циклы анимации на чистом CSS или JS. 
    *   Все микро-взаимодействия (появление списков, выпадающие меню, табы) должны реализовываться декларативно через Framer Motion с обязательным использованием `<AnimatePresence>`.
    *   *AI DX Эффект*: ИИ превосходно генерирует декларативные пропсы (`initial`, `animate`, `exit`), что гарантирует отсутствие багов с прерыванием анимации.

### 🟢 154. Внедрить паттерн семантического восстановления после ошибок (Error Recovery) (L4)
*   **Тип**: Дополнение L4
*   **Приоритет**: СРЕДНИЙ
*   **Суть**:
    *   При генерации страниц ИИ должен обязательно оборачивать сетевые компоненты в Error Boundaries и выводить понятное окно ошибки с кнопкой автоматического перезапуска запроса (Retry). Никаких пустых белых экранов.
    *   *AI DX Эффект*: Система становится устойчивой к падениям бэкенда, а ИИ автоматически учится генерировать безопасные заглушки.

### 🟢 155. Обязательное скругление кнопок и таргет-зоны 44x44px для мобильного дизайна (L7)
*   **Тип**: Дополнение L7
*   **Приоритет**: СРЕДНИЙ
*   **Суть**:
    *   Внедрить в правила верстки требование соблюдать минимальные физические размеры кликабельных зон (минимальный touch-target — 44x44px для интерактивных элементов на мобильных устройствах).
    *   *AI DX Эффект*: ИИ автоматически генерирует мобильные и адаптивные интерфейсы с удобной эргономикой.

### 🟡 156. Правила безопасного переноса SVG-кода из генератора v0.dev (L0)
*   **Тип**: Новое правило / Дополнение L0
*   **Приоритет**: ВЫСОКИЙ
*   **Суть**:
    *   При копировании интерфейсов из v0.dev обязывать ИИ заменять встроенные inline-SVG иконки (сотни строк раздутого XML-кода) на импорты легковесных компонентов из библиотеки `lucide-react`.
    *   *AI DX Эффект*: Предотвращает захламление файлов разметки тысячами строк XML-кода, снижает объем бандла и сохраняет контекстное окно ИИ чистым.
