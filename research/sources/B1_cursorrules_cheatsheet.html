Cursor Keyboard Shortcuts Cheat Sheet

This cheat sheet provides a quick overview of the most common keyboard shortcuts and AI commands for Cursor AI, including Cursor Tab, Cmd K, Chat, Composer, and @ Symbols.

Cursor Tab (AI Code Completion)

  • Open Command Palette
    Tab Tab
  • Reject Suggestion
    Esc Esc
  • Partial Accept
    Ctrl + → ⌘ + →

Cmd K (Inline Editing)

  • Open Cmd K
    Ctrl + K ⌘ + K
  • Apply Changes
    Ctrl + ↵ ⌘ + ↵
  • Cancel/Delete Changes
    Ctrl + ⌫ ⌘ + ⌫

Cmd K (Inline Editing)

  • Open Chat
    Ctrl + L ⌘ + L
  • Add Code to Chat
    Ctrl + L ⌘ + L

Composer

  • Open Composer
    Ctrl + I ⌘ + I
  • Open Full-screen Composer
    Ctrl + Shift + I ⌘ + Shift + I

@ Symbols

  • Reference File
    @filename @filename
  • Reference Function
    @functionName @functionName
  • Reference Variable
    @variableName @variableName
  • Search Codebase
    @codebase query @codebase query
  • Search Web
    @web query @web query

General

  • Open Command Palette
    Ctrl + Shift + P ⌘ + Shift + P
  • Open Settings
    Ctrl + , ⌘ + ,
  • Toggle Sidebar
    Ctrl + B ⌘ + B
  • Toggle Terminal
    Ctrl + ` ⌘ + `
  • New File
    Ctrl + N ⌘ + N
  • Save File
    Ctrl + S ⌘ + S

Remember that you can customize these shortcuts in Cursor's settings to better fit your workflow. Explore the settings to tailor Cursor to your needs and boost your productivity. Happy coding with Cursor!
