### ✅ C3: "Агентная инженерия: практическое руководство" (ЗАВЕРШЕНО)

**Ключевые находки**:
1. **6 приёмов промпт-инженерии**:
   - Контекст-фрейм (начни с ограничений)
   - Пример входа-выхода
   - Negative Prompting
   - Chunking (одна задача — один промпт)
   - Spec-first (контракт до реализации)
   - Привязка к реальности (запрет галлюцинаций)

2. **CLAUDE.md структура** (5 секций):
   - Проект, Структура директорий, Паттерны кода, Правила, Запрещено
   - 3 ошибки: слишком длинный, абстрактный, устаревший
   - Практический совет: начать с 50 строк

3. **Model Context Protocol (MCP)**:
   - Архитектура: Host → Client → Server
   - 3 примитива: Tools, Resources, Prompts
   - Транспорт: stdio (локальные), Streamable HTTP (удалённые)
   - Практика: MCP-сервер за 5 шагов

4. **Git Worktrees для AI**:
   - Параллельные сессии без конфликтов
   - Изолированные эксперименты
   - Встроенная поддержка в Claude Code

5. **3 мульти-агентных паттерна**:
   - Pipeline (конвейер): Architect → Coder → Reviewer → Tester
   - Router + Specialists (маршрутизатор)
   - Adversarial (состязательный): Generator ↔ Critic

6. **5 паттернов ошибок AI-кода**:
   - Галлюцинации API
   - Устаревший синтаксис
   - Security-дыры
   - Happy Path Only
   - Phantom Dependencies

**Метрики**: 2504 слова, февраль 2026, Codenrock

**Файл анализа**: `research/C3_agentnaya_inzheneriya_analysis.md`

### ✅ C4: "5 главных ошибок вайбкодинга" (ЗАВЕРШЕНО)

**Ключевые находки**:
1. **5 критических ошибок**:
   - Слепое доверие AI-коду (ИИ-копипаст)
   - Потеря контроля над архитектурой
   - Игнорирование краевых случаев (Happy Path Syndrome)
   - Деградация навыка отладки (бесконечный цикл промптов)
   - Ленивые промпты и плохой контекст

2. **Формула промпта**: Контекст + Роль + Задача + Ограничения

3. **Практические техники**:
   - Trust, but verify (ИИ как "гиперактивный джун")
   - Правило двух попыток для отладки
   - Defensive Prompting (защитные промпты)
   - Чек-лист перед Accept кода

4. **Метрики**: 7.4K просмотров, 18 закладок (свежая статья от 11 мая 2026)
