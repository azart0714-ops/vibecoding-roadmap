```markdown
**Контекст + Роль + Задача + Ограничения**

**Пример**:

- ✅ Хорошо: "Ты — senior React-разработчик. Создай форму логина с валидацией email/пароля, используя React Hook Form и Zod. Требования: доступность (ARIA), темная тема, мобильная адаптация."

**Defensive Prompting** — защитные промпты:
- "Проверь edge cases для пустых значений"
- "Добавь обработку ошибок для всех async операций"
- "Убедись, что код работает с null/undefined"
```

```markdown
## 🚨 5 критических ошибок вайбкодинга

### 1. ИИ-копипаст (Слепое доверие)
**Проблема**: Принимаешь код AI без проверки  
**Последствия**: Баги, уязвимости, технический долг  
**Решение**: "Trust, but verify" — ИИ как гиперактивный джун

### 2. Потеря контроля над архитектурой
**Проблема**: AI генерирует код без понимания общей картины  
**Последствия**: Спагетти-код, дублирование, несогласованность  
**Решение**: Ты — архитектор, AI — строитель

### 3. Happy Path Syndrome
**Проблема**: AI игнорирует краевые случаи  
**Последствия**: Крэши в продакшене  
**Решение**: Defensive Prompting + ручная проверка edge cases

### 4. Деградация навыка отладки
**Проблема**: Бесконечный цикл "попроси AI пофиксить"  
**Последствия**: Зависимость от AI, потеря навыков  
**Решение**: Правило двух попыток (2 промпта → ручная отладка)

### 5. Ленивые промпты
**Проблема**: "Сделай красиво" вместо конкретных требований  
**Последствия**: Неожиданный результат, потеря времени  
**Решение**: Формула промпта (Контекст + Роль + Задача + Ограничения)
```

### 3️⃣ L7: Deployment & Production

**Раздел**: "Безопасность AI-генерированного кода"

**Что добавить**:
```markdown
### 🛡️ Чек-лист перед Accept кода

**Перед тем как принять код от AI**:
- [ ] Прочитал и понял каждую строку
- [ ] Проверил edge cases (null, undefined, пустые массивы)
- [ ] Убедился в наличии обработки ошибок
- [ ] Проверил типизацию (TypeScript)
- [ ] Запустил тесты (если есть)
- [ ] Проверил безопасность (SQL injection, XSS)
- [ ] Убедился в соответствии архитектуре проекта

**Правило двух попыток**:
1. Первый промпт → AI генерирует код
2. Второй промпт → AI пытается исправить
3. Если не работает → ручная отладка (не третий промпт!)

**Почему**: Развивает навыки отладки, экономит токены, быстрее решает проблему
```
